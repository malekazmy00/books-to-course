# فجوات CoursePipelineWorkflow مقابل القرارات — 2026-10-31

- **السبب:** ملاحظة المالك على النسخة الأولى من قائد الخط (`2daa94f`). كانت تخالف القرارات في ثلاث نقاط:
  1. توقف الخط عند رفض بوابة.
  2. بحث المعرفة يجري بعد الترجمة.
  3. الصوت يخرج كتلة واحدة للكتاب.
- **الحالة:** تحليل وخطة. لا تغيير في الكود في هذا الملف.

## 1. الترتيب الصحيح (D-034، D-035، learning-companion §11–§12)

```
الاستخراج v2 ← المخطط v2
  ← بحث المعرفة (EN، قبل الترجمة): المؤلف، والسياق، والتلقي، والمفاهيم في مجالها
  ← طبقة المفاهيم (EN)
  ← القاموس: المقابلات العربية المعروفة (Wikidata، وUNTERM، وArabTerm...) + تصويت النماذج (D-050)
  ← ترجمة الكتاب، ثم ترجمة كل الإثراء بالقاموس نفسه (D-035)
  ← بحث اللغة (AR، بعد الترجمة): المصطلحات غير المحسومة، والمواضع المتعثرة، وتصير حواشي
  ← الأشكال (EN ثم AR) ← نصوص الحلقات (EN ثم AR)
  ← الصوت حلقةً حلقة ← MP3 لكل حلقة (D-038، D-042، D-044)
```

## 2. ما وجدته في الكود (قراءة فقط)

| البند | الحالة |
|---|---|
| بحث المعرفة قبل الترجمة | **ممكن:** `ResearchKnowledgeInput` يقبل `termbase_ref=None`، ويأخذ المرشحين من الوحدات (`termbase_seeds`). يحتاج `units_ref`، وهو يُنتج داخل `TranslateBookWorkflow` (prepare)، فيلزم فصل `prepare_translation_units` أو تشغيله أولًا |
| الملف المعرفي يغذّي القاموس | **غير موصول:** `TranslateBookActivities.concept_sources` يأخذ مصادر Wikidata وAGROVOC فقط، ولا يقرأ المقابلات العربية المعروفة من بحث المعرفة |
| بحث اللغة بعد الترجمة (AR) | **غير موجود في الكود:** لا وحدة ولا نشاط |
| الصوت حلقةً حلقة | **غير موصول:** `GenerateSpeechV2Workflow` ينطق تجميعة الكتاب. و`b2c_speech.text.episode.build_episode_speech_text` موجود لنص الحلقة العربي، ولم يُربط بـ workflow. ويلزم مسار لكل حلقة، ثم `EncodeEpisodeMp3Workflow` لكل حلقة |

## 3. الفشل يصير معرفة: ما قررناه وأين يُطبَّق

| المرحلة | القرار | التطبيق في الخط |
|---|---|---|
| الترجمة | D-033، D-040، D-041: كل وحدة غير مقبولة تصير حاشية مترجم، وتُنطق بصوت الكورس | موجود. الكلام بـ `notes_ref` (مسار قبول بديل)، والحلقة تأخذ نص الوحدة من حاشيتها |
| الحكم الدلالي | D-051: ما لا يُحسم يفشل مغلقًا فيصير حاشية | موجود |
| القاموس | D-039 وD-050: الخلاف يعطي `hint` لا `locked`، والضوضاء `dropped`، وغياب المحكّم يعطي hint | موجود |
| الأشكال | D-044: الرسوب يرجع إلى العنوان ووصف الكتاب المطبوع، ولا يُخترع شيء | موجود. **لكن:** الوصف غير المقبول يُسجَّل `figure_not_accepted` ولا يُقرأ، فيلزم إعلان بدل الصمت |
| **الاستخراج** | المبدأ D-033: لا يتوقف الإنتاج ولا يُحجب شيء | **مخالف:** `IngestPDFV2Workflow` يعيد `needs_review` ولا يبني مخططًا، والخط يتوقف. **المطلوب:** المتابعة بالـ parse، وتحويل صفحات `page_findings` إلى علامات جودة تنتقل إلى الوحدات، ثم إلى حاشية «النص الأصلي هنا غير واضح» |
| **المخطط** | المبدأ نفسه | **مخالف:** الخط يتوقف إن لم تقبله بوابتاه. **المطلوب:** المتابعة بأفضل مخطط مع إعلان الحدود المشكوك فيها، أو بمخطط احتياطي من الفصول، مع تسجيل السبب |
| **المفاهيم والإثراء** | D-033 | **مخالف:** الخط يتوقف إن لم تُقبل طبقة المفاهيم. **المطلوب:** الحلقات تُبنى بما قُبل، والإثراء الناقص يُعلن في الحلقة، ولا يحجب نص الكتاب |
| **الحلقات** | D-041 | جزئي: الحلقة التي لا يُقبل نصها الإنجليزي «تُتخطى». **المطلوب:** حلقة نص الكتاب وحده (النواة الأمينة، D-032)، مع إعلان غياب الملخص والأسئلة |
| الفهرسة/التضمين | — | ليست على المسار الحرج للحلقات (S5). تُضاف لاحقًا بالقاعدة نفسها |

## 4. ترتيب التنفيذ المقترح

1. **إزالة كل توقف من `CoursePipelineWorkflow`:** كل رفض يصير علامة أو حاشية ويستمر الخط، ويسجل التقرير ما تحوّل وأين.
2. **إعادة الترتيب:**
   - prepare للوحدات، ثم بحث المعرفة وطبقة المفاهيم، ثم القاموس مع المقابلات المعروفة، ثم الترجمة.
   - بعد الترجمة: ترجمة الإثراء، ثم بحث اللغة.
3. **الصوت حلقةً حلقة:**
   - `GenerateSpeechV2Input.episode_ar_ref`، وprepare يبني بـ `build_episode_speech_text`.
   - مسار لكل حلقة (أو أكثر بحد الـ 1800 ث)، ثم `EncodeEpisodeMp3Workflow` بأسماء 00..n.
4. **الاستخراج:** متابعة رغم رفض البوابة، مع علامات الجودة من `page_findings` إلى الوحدات والحواشي.
5. **بحث اللغة (AR):** بناؤه، فهو غير موجود.
