# Phase 2 — تدقيق مجموعات المرجع ونتائج OCR المحفوظة

**التاريخ:** 2026-10-04  
**النطاق:** مراجعة البيانات والسجلات الموجودة فقط؛ لا إعادة OCR، ولا تشغيل خدمات، ولا تعديل تقرير Phase 2 العام. B2C فقط.

## الخلاصة

- **Misraj-DocOCR** أقوى مرجع عربي موجود: 400 صفحة عربية image+Markdown، حقيقي واصطناعي؛ الناشر يصرّح بأن النص والبنية راجعهما خبراء. بطاقة Hugging Face تعرض Apache-2.0. هذا توثيق الناشر ورخصة المجموعة كما نُشرا، لكنه لا يثبت استقلاليًا ترخيص كل كتاب/صورة أصلية؛ لا أعتبره إذنًا تجاريًا شاملًا دون مطابقة المصادر.
- **OmniDocBench v1.6** غني بالتخطيط وترتيب القراءة والجداول: 1,651 صفحة، منها 276 صفحة كتب و159 كتابًا مدرسيًا ملونًا و665 جدولًا. لا توجد فيه صفحات عربية بحسب سمات اللغة المحلية. README تذكر التعليق اليدوي ومراجعة الخبراء؛ بيان الحقوق يقصر المجموعة على البحث ويحظر الاستخدام التجاري.
- مجموعات **KITAB-Bench** تضيف عينات عربية لمهام OCR والسطر والتخطيط والجداول. مستودع KITAB يصف التعليقات بأنها بشرية، لكن README المحلية لا تمنح رخصة واضحة لكل صور البيانات؛ رخصة MIT للكود ليست رخصة شاملة للبيانات.
- التجارب الحالية صغيرة ولا تثبت اجتياز الجودة. لا يوجد مرجع إنجليزي بشري كامل الحقوق وممثل للكتب الحديثة؛ نحتاج كتابًا مملوكًا لـB2C أو إذنًا صريحًا للاحتفاظ بالصفحات والمرجع النصي.
- لا حاجة لإعادة OCR للمرجع المحفوظ. الخطة أدناه لا تتطلب إلا فرزًا بشريًا واختيارًا ثابتًا للصفحات.

## نتائج OCR المحفوظة

النسب مأخوذة من JSONL كما هو. لا يوجد manifest كامل لإعداد تطبيع النص لكل تشغيل؛ اعتبرها مؤشرات استكشافية. احتُسب أول نجاح لكل sample ID لمنع احتساب الصفحة مرتين في سجلات OpenRouter.

| النموذج/المسار | المجموعة والصفحات الفريدة | micro CER | micro WER | median latency/صفحة | الملاحظة |
|---|---:|---:|---:|---:|---|
| Docling+RapidOCR (worker results) | Misraj، 5 | 91.34% | 99.47% | 6.66s | الاستجابات الخمس نجحت تقنيًا، لكن الدقة ضعيفة جدًا في العينة. |
| Surya 2، ناتج غير HTML | Misraj، 5 | 99.81% | 104.13% | 97.22s | لا يثبت نجاح OCR؛ edit distance قد يتجاوز 100%. |
| Surya 2، prompt ومخرج HTML المصحح | Misraj، 1 | 3.35% | 11.94% | 242.63s | صفحة واحدة فقط؛ لا تكفي للمقارنة. |
| Qwen free، أول نجاح لكل صفحة | Misraj، 5 | 48.96% | 55.13% | 13.03s | 8 نجاحات من 11 محاولة في هذه المجموعة. |
| DeepSeek Vision، أول نجاح لكل صفحة | Misraj، 5 | 38.03% | 36.60% | 13.30s | 8/8 محاولات، لكن 5 صفحات فقط. |
| Qwen free، أول نجاح لكل صفحة | OmniDocBench، 3 | 62.76% | 69.75% | 8.71s | عينة صغيرة من 3 صفحات. |
| DeepSeek Vision، أول نجاح لكل صفحة | OmniDocBench، 3 | 25.29% | 39.16% | 15.27s | عينة صغيرة، لا تعمم. |

- docling-rapidocr-results.jsonl يحوي 5 أخطاء تثبيت Docling؛ النتائج الفعلية منفصلة في docling-rapidocr-worker-results.jsonl.
- openrouter-sample-results.jsonl يسجل إعادات محاولة. على Misraj سجل Qwen 11 محاولة و8 نجاحات، وDeepSeek 8/8؛ وإجماليًا عبر الملف ظهرت 7 أخطاء HTTP/429 لـQwen. لا تُحسب retries كصفحات مستقلة.
- لا تثبت هذه النتائج اجتياز بوابة OCR.

## خطة عينة مرجعية دون إعادة OCR للمرجع

### العربية

1. ثبّت revision/source URL وSHA-256 لكل shard، وخزّن الصور على قرص البيانات دون نسخها إلى Git أو إعادة توزيعها.
2. راجع صفحات Misraj الـ400 بالاستناد إلى الصورة وMarkdown المنشور. يضع مراجعان مستقلان الوسوم: نثر/كتاب، جدول، معادلة، أعمدة/ترتيب قراءة، جودة الصورة، حقيقي/اصطناعي، وصلاحية GT. تُحال الخلافات إلى مراجع ثالث؛ لا يعدل المرجع بصمت.
3. اختر 40 صفحة بعد الوسم: 20 dev و20 holdout، وغطّ قدر الإمكان الجداول والمعادلات والأعمدة والصور منخفضة الجودة. لا تملأ نقص الصفحات الواقعية بالاصطناعي.
4. داخل كل فئة، رتّب UUID حسب SHA256(seed || uuid) ثابت وخذ الحصة المحددة. ضع صفحات الكتاب الواحد في partition واحد كلما أمكن. خزّن UUID وhash الصورة والوسوم وقرار التحكيم في manifest داخلي.
5. لا تستخدم holdout لضبط النموذج أو prompt. قِس CER/WER لكل فئة، وTEDS/MARS للجداول والبنية، وترتيب القراءة وprovenance وlatency وpeak RSS. اعرض العربية والإنجليزية منفصلتين.

### الإنجليزية والحدود

لا يوجد حاليًا مرجع إنجليزي بشري بحقوق موثقة على مستوى الكتب. أنشئ مجموعة مقابلة من كتاب يملكه B2C أو إذن صريح يغطي حفظ الصفحات والـGT. يمكن استخدام OmniDocBench في البحث الداخلي فقط؛ لا يدخل holdout التجاري ولا يعاد توزيع محتواه. تشغيل OCR لاحقًا يكون على الصفحات المختارة فقط بعد تثبيت العتبات والتطبيع والإعدادات.

اقترح في manifest تحديد rights_scope: research_only لـOmniDocBench؛ وdataset_license_apache2_source_rights_unverified لـMisraj حتى مراجعة مصادر الأصول؛ وproject_owned_or_permission_verified لعينة B2C الإنجليزية بعد إثبات الإذن.
